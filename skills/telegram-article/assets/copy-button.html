Copy for Telegram

The Article editor does not understand HTML source — tags would appear as plain text. It understands formatting from the clipboard. The button below puts exactly that there.

  1. Press Copy with formatting
  2. In Telegram: paperclip 📎 → "Article"
  3. Paste: Ctrl + V (⌘ + V on Mac)
  4. Check the result — if a table did not survive, rebuild it with the ▦ button

⚠️ The Article editor requires Telegram Premium and has no autosave — do not close the window before sending. Test on one paragraph first.
