Write proper articles in Telegram, from your agent

This message was not typed here. An AI agent wrote it as a web page; it was copied once and pasted in — headings, tables and all. That is the telegram-article skill.

Formatting in Telegram is structural, not visual. You pick an element's role; the client decides how it looks.

The problem

The Article editor is visual. Paste HTML source and you get the literal text <h1>Title</h1> on screen. The fix is copying a rendered page instead of its source — the clipboard carries structure.

What the editor gives you

ElementFor
Headings, 6 levelsStructure — and your only size control
TablesComparable rows, like this one
ListsSteps, facts, checklists
Code blocks 🎬Commands, with highlighting
FormulasLaTeX, inline or block

What it does not

  • No font picker, no font size — heading level is the only size control
  • No text color, only highlight
  • No autosave — close before sending and the text is gone

How it works

  1. You describe the article in plain language
  2. The agent writes it as a page with a copy button
  3. You paste into 📎 → Article
  4. Images and formulas are added in the editor

The undocumented part

Telegram documents paste behavior nowhere, and guides claim tables cannot be pasted. Tested on Desktop with Premium, 18 Sep 2026: tables transferred. Areas still scale as πr2 and water is H2O.

new ClipboardItem({ 'text/html': blob, 'text/plain': blob })

Check this message: six heading levels, a table with an emoji, two lists, a quote, a code block, a divider, super/subscript, inline code. Anything missing was stripped.

Как писать нормальные статьи в Telegram руками агента

Это сообщение здесь не набирали. ИИ-агент написал его как веб-страницу, текст скопировали одним нажатием и вставили — вместе с заголовками и таблицами. Это навык telegram-article.

Оформление в Telegram структурное, а не визуальное. Вы выбираете роль элемента, а как он выглядит — решает клиент.

Проблема

Редактор статей визуальный. Вставьте в него HTML-код — и на экране будет буквальный текст <h1>Заголовок</h1>. Решение — копировать отрендеренную страницу вместо исходника: буфер несёт структуру.

Что редактор умеет

ЭлементДля чего
Заголовки, 6 уровнейСтруктура — и единственная «крупность»
ТаблицыОднородные строки, как эта
СпискиШаги, факты, чек-листы
Блоки кода 🎬Команды, с подсветкой
ФормулыLaTeX, строкой или блоком

Чего не умеет

  • Нет выбора шрифта и кегля — крупность задаёт только уровень заголовка
  • Нет цвета текста — только выделение
  • Нет автосохранения — закрыли до отправки, текст пропал

Как это работает

  1. Вы своими словами описываете статью
  2. Агент пишет её как страницу с кнопкой копирования
  3. Вы вставляете в 📎 → «Статья»
  4. Картинки и формулы добавляются уже в редакторе

Недокументированная часть

Telegram нигде не описывает поведение вставки, а гайды утверждают, что таблицы вставить нельзя. Проверено на Desktop с Premium 18.09.2026: таблицы переносятся. Площадь по-прежнему считается как πr2, а вода — H2O.

new ClipboardItem({ 'text/html': blob, 'text/plain': blob })

Проверьте это сообщение: шесть уровней заголовков, таблица с эмодзи, два списка, цитата, блок кода, разделитель, надстрочный и подстрочный знаки, моноширинный текст. Всё, чего нет, — срезалось при вставке.
