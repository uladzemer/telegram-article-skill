Write proper articles in Telegram, from your agent

This message was not typed in Telegram. It was written by an AI agent as a web page, copied once, and pasted here — headings, tables, lists and all. That is the whole point of the telegram-article skill.

Formatting in Telegram is structural, not visual. You choose an element's role; the client decides how it looks.

The problem it solves

Telegram's Article editor is a visual editor. Paste HTML source into it and you get the literal text <h1>Title</h1> on screen. Every agent that helpfully hands you an HTML file to "paste into Telegram" produces exactly that failure.

The fix is not a better HTML file. It is copying a rendered page instead of its source — the clipboard carries structure, and the editor reads it.

What the editor actually gives you

ElementWhat it is for
Headings, 6 levelsStructure — and your only size control
TablesComparable rows, like this one
ListsOrdered steps, unordered facts, checklists
QuotesFull-width, or centered as an accent
Code blocksCommands and config, syntax highlighted
Collapsible blocksLong caveats the reader opens on demand
Media 🎬Images, video, audio, carousels between paragraphs
FormulasLaTeX, inline or as a block

What it does not give you

  • No font picker — the typeface is the client's
  • No font size — heading level is the only size control
  • No text color — only a highlight and table row shading
  • No autosave — close the editor before sending and the text is gone

So when someone asks for "a nicer font", the honest answer is: pick a heading level and use bold. Everything visual belongs to Telegram, not to the author.

How the skill works

  1. You describe the article you want, in plain language
  2. The agent writes it as a rendered page with a copy button
  3. You press the button and paste into 📎 → Article
  4. Images and formulas are added in the editor, where the draft marks their place

The part nobody documented

Telegram describes paste behavior nowhere, and published guides state that tables cannot be pasted at all. Tested on Telegram Desktop with Premium on 18 September 2026: tables transferred, along with everything else structural.

Because this is undocumented and may differ per client, the skill tells users to test one paragraph first, and to rebuild a table with the ▦ button if it ever fails.

Technical detail, for the curious

The copy button writes two clipboard flavors at once, so the same press works for the Article editor and for a plain message field:

const item = new ClipboardItem({
  'text/html':  new Blob([html],  { type: 'text/html' }),
  'text/plain': new Blob([plain], { type: 'text/plain' })
});
await navigator.clipboard.write([item]);

Areas scale as πr2, water is H2O, and an article holds 32 768 characters — eight times a normal message.

What to look for in this message

If the paste worked, you are seeing: six heading levels, two tables (one with an emoji), a bulleted list, a numbered list, a quote, a code block, a divider, super- and subscript, inline code, and links. Anything missing was stripped and must be added by hand.

Как писать нормальные статьи в Telegram руками агента

Это сообщение не набирали в Telegram. Его написал ИИ-агент в виде веб-страницы, текст скопировали одним нажатием и вставили сюда — вместе с заголовками, таблицами и списками. В этом весь смысл навыка telegram-article.

Оформление в Telegram структурное, а не визуальное. Вы выбираете роль элемента, а как он выглядит — решает клиент.

Какую проблему он решает

Редактор статей — визуальный. Если вставить в него HTML-код, на экране появится буквальный текст <h1>Заголовок</h1>. Любой агент, который выдаёт «вот HTML-файл, вставьте в телеграм», приводит ровно к этому.

Решение — не «файл получше», а копировать отрендеренную страницу вместо исходника: буфер обмена несёт структуру, и редактор её принимает.

Что редактор реально умеет

ЭлементДля чего
Заголовки, 6 уровнейСтруктура — и единственная «крупность»
ТаблицыОднородные строки, как эта
СпискиШаги по порядку, факты, чек-листы
ЦитатыНа всю ширину или выноской по центру
Блоки кодаКоманды и конфиги, с подсветкой
Сворачиваемые блокиДлинные оговорки, которые читатель раскроет сам
Медиа 🎬Картинки, видео, аудио, карусели между абзацами
ФормулыLaTeX, строкой или блоком

Чего он не умеет

  • Нет выбора шрифта — гарнитуру задаёт клиент
  • Нет размера кегля — крупность задаётся только уровнем заголовка
  • Нет цвета текста — только выделение и заливка строк таблицы
  • Нет автосохранения — закрыли редактор до отправки, текст пропал

Поэтому на просьбу «сделай шрифт покрасивее» честный ответ такой: выберите уровень заголовка и используйте жирный. Всё визуальное принадлежит Telegram, а не автору.

Как работает навык

  1. Вы своими словами описываете нужную статью
  2. Агент пишет её как отрендеренную страницу с кнопкой копирования
  3. Вы жмёте кнопку и вставляете в 📎 → «Статья»
  4. Картинки и формулы добавляются уже в редакторе — в черновике помечено, где именно

То, чего никто не описал

Telegram нигде не документирует поведение вставки, а опубликованные гайды прямо утверждают, что таблицы вставить нельзя. Проверено на Telegram Desktop с Premium 18 сентября 2026 года: таблицы переносятся, как и всё остальное структурное.

Поскольку это недокументировано и может отличаться на разных клиентах, навык советует сначала проверить на одном абзаце, а если таблица не доехала — собрать её кнопкой ▦.

Техническая деталь для любопытных

Кнопка копирования кладёт в буфер сразу два слоя, поэтому одно нажатие годится и для редактора статей, и для обычного поля сообщения:

const item = new ClipboardItem({
  'text/html':  new Blob([html],  { type: 'text/html' }),
  'text/plain': new Blob([plain], { type: 'text/plain' })
});
await navigator.clipboard.write([item]);

Площадь считается как πr2, вода — это H2O, а статья вмещает 32 768 символов: в восемь раз больше обычного сообщения.

Что проверить в этом сообщении

Если вставка удалась, вы видите: шесть уровней заголовков, две таблицы (в одной эмодзи), маркированный список, нумерованный список, цитату, блок кода, разделитель, надстрочный и подстрочный знаки, моноширинный текст и ссылки. Всё, чего не хватает, срезалось при вставке и добавляется вручную.
